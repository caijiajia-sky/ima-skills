## 使用建议

1. **日常对话**: 推荐 `female-tianmei` 或 `female-yujie`
2. **讲故事/朗读**: 推荐 `female-yujie` 或 `male-jieshuo`
3. **新闻播报**: 推荐 `Chinese (Mandarin)_News_Anchor`
4. **儿童内容**: 推荐 `female-shaonv` 或 `male-yuanbao`
5. **正式场合**: 推荐 `male-jieshuo` 或 `Chinese (Mandarin)_Gentleman`

- 声音列表可能随 API 更新而变化
- 部分声音可能需要特定权限
