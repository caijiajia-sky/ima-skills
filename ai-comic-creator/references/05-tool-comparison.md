## 四、MiniMax mmx CLI 使用

### 安装
```bash
npm install -g mmx-cli
```

### 认证
```bash
mmx auth login --api-key "sk-cp-your-api-key"
mmx auth status
mmx quota
```

### 图片生成
```bash
# 基础生图
mmx image "图片描述提示词"

# 指定宽高比
mmx image "描述" --aspect-ratio 16:9

# 生成并保存
mmx image generate --prompt "描述" --out image.png
```

### 支持的宽高比
| 比例 | 用途 |
|------|------|
| 1:1 | 正方形 |
| 16:9 | 横版 |
| 9:16 | 竖版 |
| 4:3 | 经典照片 |
| 21:9 | 超宽屏/公众号封面 |

## 五、即梦AI图生视频

### 四种模式
1. 文生视频 - 纯文字生成视频
2. 图片生视频 - 单张图片转视频
3. 首尾帧模式 - 起始+结束图片生成过渡视频
4. 故事模式 - 多张图片串联成完整故事

### 运动提示词公式
```
[谁] + [在哪里] + [做什么动作] + [动作细节] + [环境互动] + [镜头运动]
```

### 常用镜头运动
| 运动 | 英文 | 效果 |
|------|------|------|
| 推进 | push in, zoom in | 聚焦 |
| 后拉 | pull out, zoom out | 展示全貌 |
| 环绕 | orbit around | 环绕展示 |
| 跟随 | follow | 跟踪 |
| 固定 | static | 静止 |

### 角色一致性（视频）
1. 使用角色参考图
2. 保持生成参数一致
3. 先图后视频（先图生图→再图生视频）
