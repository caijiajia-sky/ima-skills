# 角色一致性完全解决方案

## 一、核心痛点

AI绘画每次生成都是"不同的人"：
- 第一张图是黑长直女性
- 第二张图变成短发女性
- 第三张图变成了完全不同的人

这对连载故事、系列漫画、IP形象用户是致命问题。

## 二、四大核心方法

### 方法1：Seed值控制法

**原理**：Seed（种子值）是AI生成图片的随机起点，同一Seed值能产生相似但不完全相同的图片。

**使用步骤**：
1. 生成第一张满意的图
2. 查看该图的Seed值
3. 后续生成使用相同Seed值

**局限性**：
- 对人物特征还原度有限
- 换衣服/场景时特征可能漂移
- 不同模型对Seed敏感度不同

### 方法2：Lora模型训练（最专业）

**原理**：LoRA是轻量级模型微调技术，训练特定人物/风格的专属模型。

**训练流程**：
1. 收集10-20张同一人物的不同角度图片
2. 统一尺寸、去除背景
3. 使用SD WebUI或在线平台训练
4. 加载LoRA后生成固定角色

### 方法3：参考图控制（推荐）

| 工具 | 操作 | 参数 |
|------|------|------|
| Stable Diffusion | ControlNet Reference Only | Style Fidelity: 0.8-1.0 |
| Midjourney | --sref [图片链接] | --sw 80 |
| 即梦AI | 上传参考图，选择"角色参考"模式 | - |

### 方法4：结构化提示词（最简单）

**结构化人设描述模板**：
```
## 面部特征
- 脸型: [圆脸/方脸/鹅蛋脸]
- 眼睛: [形状+颜色+眼神]
- 眉毛: [粗细+形状]
- 鼻子: [大小+形状]
- 嘴巴: [唇色+表情]

## 发型发色
- 发型: [长短+卷直+造型]
- 发色: [颜色+高光]

## 体型服饰
- 身高: [高/中等/矮]
- 服装: [风格+颜色+款式]
- 配饰: [眼镜/耳环/项链等]
```

## 四、角色一致性评分卡

检查点：
- [ ] 面部轮廓相似度 > 80%
- [ ] 眼睛形状和颜色一致
- [ ] 发型发色一致
- [ ] 肤色统一
- [ ] 整体风格一致

## 五、表情变化控制技巧

**核心原则**：固定面部结构描述，只改变表情相关词汇，保持发型、服装不变。

```
[固定部分] + smiling → [变化部分] + crying
[固定部分] + angry → [变化部分] + laughing
```

## 六、常见问题解决

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 脸型总变 | 提示词不具体 | 添加详细面部特征描述 |
| 发色不一致 | 随机性太高 | 指定发色，降低变异度 |
| 衣服不一样 | 描述不够详细 | 详细描述服装款式颜色 |
| 整体不像 | 需要参考图 | 使用Reference功能 |
| 表情僵硬 | 缺少动态描写 | 添加表情相关的动作描写 |
