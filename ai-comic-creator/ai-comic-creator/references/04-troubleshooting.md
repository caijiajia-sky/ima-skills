# 常见问题解决方案

## 一、文字乱码

### 原因
AI生图模型对复杂文字渲染能力有限

### 解决方案
1. ❌ 不要在提示词中包含文字内容
2. ✅ 只描述视觉场景、人物动作、表情、环境
3. ✅ 在公众号排版时手动添加对话框和文字
4. ✅ 使用图片编辑工具后期处理
5. ⚡ 如果必须嵌入文字，使用豆包Seedream的文字嵌入公式

### 示例对比

| 类型 | 提示词 | 结果 |
|------|--------|------|
| ✅ 正确 | 中年女性坐着刷手机，表情担忧，手机屏幕显示搜索界面 | 正常出图 |
| ❌ 错误 | 中年女性坐着刷手机，屏幕上显示"肩膀痛是肩周炎吗？"的文字 | 乱码 |

## 二、人物不一致

### 原因
- 每次生成使用不同的随机种子
- 特征描述不够固定
- 模型版本变化

### 解决方案

**方案1：固定前缀法（最简单）**
- 编写50-100字的固定角色描述
- 每次生成都以这段描述开头
- 仅修改动态动作和场景部分

**方案2：参考图法**
- 生成一个满意的角色图
- 保存为参考图
- 后续生成时上传参考图

**方案3：Seed固定法**
- 生成首张满意角色图
- 记录该图的Seed值
- 后续所有该角色的图都使用相同Seed

**方案4：LoRA训练法（最专业）**
- 准备15-25张角色不同角度图
- 使用Stable Diffusion WebUI + LoRA训练
- 训练专属角色模型文件

## 三、场景混乱

### 原因
- 提示词元素过多
- 主次关系不明确
- 构图不统一

### 解决方案
1. **每张图只传达1个核心信息**
2. 减少场景元素
3. 明确主次关系
4. 指定构图类型（居中构图、对称构图等）

## 四、风格不统一

### 解决方案
1. 明确风格关键词，每次都包含
2. 使用负面提示词排除其他风格
3. 将风格词放在提示词前面

## 五、图片质量低

### 解决方案
1. 添加画质提升词：8K, ultra HD, highly detailed, professional illustration
2. 使用负面提示词排除低质量：low quality, blurry, pixelated
3. 选择更高分辨率的模型设置
4. 迭代优化提示词

## 六、提示词超长

### 解决方案
1. 即梦提示词不超过800字——精简固定前缀
2. 使用更简洁的描述语言
3. 删除重复信息
4. 分步骤生成（先简单生成，再细化调整）

## 七、构图不满意

### 解决方案
1. 在提示词中明确指定构图类型
2. 指定镜头角度（俯视/仰视/平视）
3. 指定景别（特写/中景/全景）
4. 添加摄影参数（焦段/光圈）

## 八、色彩不协调

### 解决方案
1. 在提示词中明确色调关键词
2. 指定配色方案（暖色调/冷色调/低饱和/高饱和）
3. 参考配色方案参考表

| 内容类型 | 推荐配色 |
|---------|---------|
| 健康科普 | 暖橙+清新蓝 |
| 温馨治愈 | 米白+淡粉+暖黄 |
| 专业权威 | 白底+蓝字 |
| 情感共鸣 | 对比色+渐变背景 |
