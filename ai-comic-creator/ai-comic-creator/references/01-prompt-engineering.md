# 提示词工程完整参考

## 一、提示词万能公式（8维度）

```
[画风+质量] + [角色描述] + [动作+表情] + [服装+细节] + [场景+环境] + [镜头+构图] + [光线+氛围] + [技术参数]
```

### 各维度详解

| 维度 | 作用 | 示例 |
|------|------|------|
| 画风+质量 | 确定整体视觉风格和质量 | Korean webtoon style, ultra-high quality |
| 角色描述 | 人物核心外貌特征 | 23岁亚洲女性，鹅蛋脸，丹凤眼，长直发 |
| 动作+表情 | 人物当前状态 | 右手按压左肩，眉头紧皱，表情痛苦 |
| 服装+细节 | 穿着和配饰 | 白色棉质家居服，左手腕银手镯 |
| 场景+环境 | 背景和场景 | 明亮的客厅，下午阳光，灰色沙发 |
| 镜头+构图 | 拍摄视角 | 中近景，平视角度，人物居中构图 |
| 光线+氛围 | 光影和情绪 | 自然光，温暖氛围，柔和色调 |
| 技术参数 | 分辨率和格式 | 8K ultra HD, 16:9, highly detailed |

## 二、四要素速记公式

```
[场景描述] + [人物描述] + [动作/表情] + [画风/色调]
```

适用于快速编写，不需要极致精准的场景。

## 三、豆包Seedream 4.0 五大公式

### 3.1 画面描述公式
```
【主体】+【动作】+【环境】，【风格】+【色彩】+【光影】+【构图】
```
示例：穿汉服的Q版少女，手持团扇在竹林中漫步，新国风插画风格，青绿色调，柔光侧逆光，居中构图

### 3.2 专业术语公式
```
【镜头类型】+【主体】，【材质/光影】【参数】，【风格关键词】
```
技巧：用英文专业术语效果更好（Macro lens shot > 微距镜头）

### 3.3 场景适配公式
```
【主体描述】，用于【具体用途】，需【风格/元素】强化【目标】
```
示例：磨砂质感咖啡杯放在木质桌面上，晨光斜射，用于小红书早餐博主封面

### 3.4 文字嵌入公式
```
生成【载体】，需包含文字"【XXX】"，字体【风格】，颜色【XX】，位置【XX】
```
注意：只在豆包Seedream 4.0中有效，其他模型可能产生乱码

### 3.5 组图生成公式
```
生成【数量】张[主题]图，每张需包含【核心元素】，风格保持【XX】，差异化在【XX】
```
示例：生成3张电动汽车仰视图，统一低角度广角构图，差异点在轮毂样式

## 四、即梦AI 9大高阶技巧

### 4.1 细节决定成败
- 从材质到光影都要精准描述
- 包含颜色、材质、情绪、天气要素

### 4.2 叙事美学
- 埋下情感线索让观者自动脑补
- 重点刻画3个核心叙事点：人物状态、环境特征、情绪载体

### 4.3 摄影参数控制
| 焦段 | 效果 | 场景 |
|------|------|------|
| 35mm | 自然随性 | 街拍、环境人像 |
| 50mm | 真实视角 | 纪实摄影 |
| 85mm | 虚化美颜 | 人像特写 |

### 4.4 光影炼金术
| 光效 | 情绪 | 场景 |
|------|------|------|
| 黄金时刻 | 温暖柔和 | 温馨场景 |
| 逆光剪影 | 神秘轮廓 | 戏剧冲突 |
| 硬质光线 | 制造冲突 | 紧张氛围 |

### 4.5 构图法则
- 三分法则：主体偏离中心
- 引导线设计：用道路/河流牵引视线
- 对称美学：建筑摄影灵魂

### 4.6 风格熔炉
- 保留1个主风格+2个核心混搭元素
- 避免无意义的风格混搭

### 4.7 画幅适配
| 比例 | 适用平台 |
|------|---------|
| 1:1 | Instagram |
| 16:9 | B站横屏 |
| 9:16 | 抖音、小红书 |
| 3:4 | 小红书人像 |
| 21:9 | 公众号封面 |

### 4.8 概念杂交
让矛盾要素产生化学反应（如：蒸汽朋克武士+霓虹纹路）

### 4.9 迭代进化
- 基础版：主体+环境
- 进阶版：添加细节特征
- 终极版：注入情绪DNA

## 五、提示词优化技巧

1. **聚焦核心情感**：用动作具象化抽象概念
2. **场景细节补充**：补充弱化版的场景符号
3. **多版本备选**：同一动作生成2-3个不同动态备选
4. **使用材质词**：rough skin, pores, weathered face 去除AI塑料感
