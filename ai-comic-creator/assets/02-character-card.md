# 角色卡模板

## 使用说明
为每个核心角色填写一张角色卡。后续所有AI生图提示词必须以"固定描述词"开头，确保角色一致性。

---

## 角色卡

### 基本信息
```yaml
角色名: 
昵称: 
身份定位: 
性格标签: [2-3个关键词，如：坚韧独立、内敛温柔]
角色类型: □ 治愈系 □ 热血系 □ 温柔系 □ 搞笑系 □ 专业系
```

### 外貌特征（固定不变）
```yaml
年龄: 
性别: 
种族/肤色: 
脸型: 
眼睛: [形状+颜色+特点]
鼻子: 
嘴巴: 
发型: [长度+颜色+样式]
体型: 
肤色: 
```

### 标志性特征（记忆点）
```yaml
标志物: [如：银色眼镜、左耳耳钉、围裙、听诊器]
习惯动作: [如：紧张时摸耳钉、思考时轻咬下唇]
特殊标记: [如：右手虎口老茧、左眉小疤]
```

### 服装系统
```yaml
日常装: 
工作装: 
特殊装: 
```

### AI提示词固定前缀

> ⚠️ 这是最重要的部分！每次生成都必须以这段描述开头。

```
[在此填写50-100字的固定角色描述，包含：年龄+性别+外貌核心特征+服装+画风]
```

**示例**：
```
52岁亚洲中年女性，短发微卷，表情丰富，穿着休闲家居服，手绘漫画风格，简洁线条，暖橙色和淡蓝色配色
```

```
中年男性医生，白大褂，戴银色眼镜，40岁左右，面带微笑，专业医学风格，明亮诊所环境，自然光线
```

### 表情参考
```yaml
常用表情1: [描述] → 提示词: [如：bright smile, happy expression]
常用表情2: [描述] → 提示词: [如：furrowed brows, painful expression]
常用表情3: [描述] → 提示词: [如：concerned, worried look]
```

### 动作参考
```yaml
常用动作1: [描述] → 提示词: [如：right hand pressing left shoulder]
常用动作2: [描述] → 提示词: [如：sitting on sofa, rubbing shoulder]
常用动作3: [描述] → 提示词: [如：standing, holding medical book]
```
