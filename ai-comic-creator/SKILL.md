# AI漫画创作大师

> 从0到1到N——帮你用AI完成漫画选题、角色设计、提示词构建、绘图生成、图文整合与发布的全流程。

---

## 适用场景

- ✅ 想用AI创建漫画系列但不知从何入手
- ✅ 已有文案/选题，需要生成匹配的漫画图片
- ✅ 需要设计统一风格的角色并保持一致性
- ✅ 想批量生产漫画内容用于公众号/自媒体
- ✅ 想把漫画动态化做成漫剧视频
- ❌ 纯手绘漫画（不涉及AI工具）
- ❌ 只需要单一图片生成（不涉及漫画创作流程）
- ❌ 需要3D建模或专业动画制作

## 执行流程

### Step 0: 定位确认（你处于哪个阶段？）

⚠️ **这是收到请求后的第一个动作，不可跳过。**

**首动流程**：
1. 从用户消息中提取关键词，尝试推断阶段
2. 如果无法推断，主动向用户提问：
   > "我帮你梳理一下当前进度，请选择你目前的情况：
   > A. 从零开始，还没有选题
   > B. 已有选题/文案，需要设计角色和画图
   > C. 已有角色设定，需要生成图片
   > D. 图片都做好了，需要整合发布
   > E. 想把漫画做成动态视频/漫剧
   > F. 想批量生产或变现"
3. 根据用户选择，进入对应执行路径

| 用户选择 | 起步阶段 | 执行路径 |
|---------|---------|---------|
| A | 0（从零开始） | Step 1 → 2 → 3 → 4 → 5 → N |
| B | 1（已有选题） | Step 2 → 3 → 4 → 5 |

### Step 1: 选题策划（从0到1的起点）

**前置条件**：用户处于阶段0（从零开始）
**输入**：用户的专业背景、兴趣方向
**输出**：漫画选题定位表（见 [assets/01-topic-planning.md](./assets/01-topic-planning.md)）

**目标**：确定漫画的选题方向、目标受众和内容定位。

#### 1.1 选题方向决策

| 方向 | 适合人群 | 变现潜力 | 竞争度 |
|------|---------|---------|-------|
| 健康科普漫画 | 医疗/康复从业者 | ⭐⭐⭐⭐⭐ | 低 |
| 术理/观点类漫画 | 有独特见解者 | ⭐⭐⭐⭐ | 中 |
| 治愈系日常漫画 | 善于观察生活者 | ⭐⭐⭐ | 高 |
| 搞笑/魔改漫画 | 幽默感强 | ⭐⭐⭐⭐ | 高 |
| 知识科普漫画 | 专业领域专家 | ⭐⭐⭐⭐⭐ | 低 |
| 情感/生活漫画 | 善于共情者 | ⭐⭐⭐ | 高 |

#### 1.2 选题三要素

1. **人群定位**：你的读者是谁？（年龄、职业、痛点）
2. **价值主张**：你的漫画解决什么问题？（教育/娱乐/情感共鸣）
3. **差异化**：你和同类内容的区别是什么？（专业背景/独特画风/稀缺选题）

#### 1.3 选题验证

- 在目标平台搜索同类选题，查看数据表现
- 确认选题是否具有"可系列化"属性（能否持续产出）
- 评估自己的专业储备是否足够支撑20+期内容

**输出**：一份《漫画选题定位表》（见 [assets/01-topic-planning.md](./assets/01-topic-planning.md)）

⏸ **暂停确认**：选题定位表完成后，须向用户展示并等待确认再进入Step 2。
确认话术：> "以上是选题定位，请确认是否满意。确认后我将继续设计角色。"

### Step 2: 角色设计（打造辨识度）

**前置条件**：Step 1已完成，选题定位表已确认
**输入**：选题方向、目标受众、内容类型
**输出**：角色卡文档（1-3个角色的完整设定 + 固定描述词前缀）

**目标**：设计1-3个核心角色，确保AI生成时保持一致性。

#### 2.1 角色设计流程

```
确定角色定位 → 基础特征设计 → 服装设计 → 细节添加 → 建立角色卡
```

#### 2.2 角色卡模板

每个角色必须填写角色卡，后续所有生成以此卡为准：

```yaml
角色名: [名字]
身份定位: [职业/角色类型]
性格标签: [2-3个关键词]

# 外貌特征（固定不变）
脸型: [描述]
眼睛: [描述]
发型: [描述]
体型: [描述]
肤色: [描述]

# 服装系统
日常装: [描述]
工作装: [描述]

# 标志性特征（记忆点）
标志物: [如：银色眼镜、左耳耳钉]
习惯动作: [如：紧张时摸耳钉]

# AI提示词固定前缀
固定描述词: "[核心外貌+服装的关键词，每次生成必须包含]"
```

#### 2.3 辨识度设计方案（按需选择）

| 方案 | 核心逻辑 | 适用场景 |
|------|---------|---------|
| 缺陷锚定法 | 加入面部缺陷词（雀斑/疤痕/牙缝） | 写实风格角色 |
| 基因融合法 | 用名人特征混搭（舒淇眼距+杜鹃清冷） | 似曾相识但独特 |
| 动物拟人法 | 用动物特征映射（狐狸眼/鹰钩鼻） | 夸张/拟人角色 |
| 地域血统法 | 精确到民族血统（藏族/蒙古族） | 文化类内容 |
| 标志物绑定法 | 一个剪影即可识别（红护目镜/独眼罩） | IP化角色 |
| 画风对抗法 | 用艺术家风格解构（席勒/洛克威尔） | 艺术向内容 |

#### 2.4 IP形象三要素（公众号漫画核心）

1. **角色设定**：外貌特征（发型/服装/配饰）+ 性格特点 + 口头禅/标志性动作 + 背景故事
2. **视觉风格**：统一的脸型比例 + 固定的眼睛大小和位置 + 一致的服装风格 + 专属配色方案
3. **表情系统**：开心/难过/生气/惊讶等基础表情 + 每种表情的固定画法 + 情绪表达的夸张程度

#### 2.5 AI辅助IP设计四步流程（来源：AI漫画IP设计完整指南）

```
第一步：生成基础形象 → 用AI生成多个候选IP形象
第二步：确定核心角色 → 选择最具辨识度的一个进行细化
第三步：建立素材库 → 正面/侧面/背面视角 + 各种表情 + 常用动作 + 服装变体
第四步：固定提示词模板 → 为后续生成建立标准化的提示词
```

#### 2.6 角色一致性锁定方案

| 方案 | 操作方法 | 适合工具 | 一致性 | 难度 |
|------|---------|---------|-------|------|
| **固定前缀法**（推荐） | 每次生成提示词以固定角色描述开头 | 所有工具 | ⭐⭐⭐ | 低 |
| **参考图法**（推荐） | 生成满意角色图后作为后续参考 | 即梦/Midjourney | ⭐⭐⭐⭐ | 低 |
| **Seed固定法** | 记录首张满意图的Seed值，后续复用 | 所有支持Seed的工具 | ⭐⭐⭐⭐ | 中 |
| **Lora训练法** | 用15-25张角色图训练专属模型 | Stable Diffusion | ⭐⭐⭐⭐⭐ | 高 |

**进阶：角色一致性评分卡**（检查5项）：
- [ ] 面部轮廓相似度 > 80%
- [ ] 眼睛形状和颜色一致
- [ ] 发型发色一致
- [ ] 肤色统一
- [ ] 整体风格一致

**固定前缀法示例**（健康科普漫画）：
```
固定前缀：52岁亚洲中年女性，短发微卷，表情丰富，穿着休闲家居服，手绘漫画风格，简洁线条，暖橙色和淡蓝色配色

分镜1 = 固定前缀 + 厨房场景，右手扶肩，表情痛苦
分镜2 = 固定前缀 + 客厅场景，坐姿揉肩膀
分镜3 = 固定前缀 + 诊所室内，认真听讲
```

**输出**：角色卡文档（见 [assets/02-character-card.md](./assets/02-character-card.md)）

⏸ **暂停确认**：角色卡完成后，必须向用户展示角色卡全文并等待确认后再进入Step 3。
确认话术：> "以上是角色卡设定，请确认是否满意。如有调整请告诉我，确认后我将继续编写提示词。"

### Step 3: 提示词工程（核心技能）

**前置条件**：Step 2已完成，角色卡已确认
**输入**：角色卡中的固定描述词 + 分镜文案
**输出**：每格分镜的完整提示词（含负面提示词）

**目标**：掌握结构化提示词方法，精准控制AI生成效果。

#### 3.1 提示词万能公式（默认首选）

适用于：需要精细控制画面的正式创作场景

```
[画风+质量] + [角色描述] + [动作+表情] + [服装+细节] + [场景+环境] + [镜头+构图] + [光线+氛围] + [技术参数]
```

#### 3.2 四要素速记公式（快速草稿）

适用于：用户说"快速出图"或"简单画一下"时使用

```
[场景描述] + [人物描述] + [动作/表情] + [画风/色调]
```

#### 3.3 漫画图片提示词模板（中文工具场景）

适用于：使用即梦/豆包等中文AI工具时的本地化写法

```
[人物名]，[性格/身份关键词]，[动作或姿态]，[服饰描述]，[面部表情]，[背景元素]，[画面氛围]，[风格关键词]
```

**选择规则**：默认使用3.1万能公式；如果用户说"快速出图"或"简单画一下"→用3.2；如果使用即梦/豆包等中文工具→用3.3。

#### 3.4 提示词编写铁律

1. **绝不在提示词中包含文字**——AI模型文字渲染能力有限，对话/标题在排版时手动添加
2. **每张图只传达1个核心信息**——避免元素过多导致场景混乱
3. **风格关键词前置**——主要风格放前面，辅助风格放后面
4. **固定特征不变，只变动动态**——保持角色一致性
5. **包含负面提示词**——排除不需要的元素

#### 3.5 负面提示词模板

```
ugly, deformed, bad anatomy, bad proportions, low quality, blurry, pixelated, 
extra fingers, missing fingers, distorted face, asymmetric eyes, 
watermark, text, multiple heads, extra limbs
```

#### 3.6 风格关键词速查

| 风格 | 英文提示词 | 中文提示词 | 适用场景 |
|------|----------|----------|---------|
| 温暖治愈 | warm, healing, cozy, soft colors | 温暖，治愈，柔和色调 | 健康科普、日常 |
| 手绘漫画 | hand-drawn, comic style, clean lineart | 手绘漫画风格，简洁线条 | 知识科普、术理漫画 |
| 宫崎骏 | Hayao Miyazaki style, hand-drawn, warm colors | 宫崎骏风格，手绘水彩，自然光影 | 治愈系、自然主题 |
| 新海诚 | Makoto Shinkai style, dreamy sky, dramatic lighting | 新海诚风格，梦幻光影，渐变天空 | 唯美场景、情感 |
| 皮克斯3D | Pixar style, 3D animation, round characters | 皮克斯风格，3D卡通，圆润可爱 | 儿童向、萌系 |
| 韩漫 | Korean webtoon style, beautiful characters | 韩漫风格，精致画面，时尚人物 | 都市情感、漫剧 |
| 赛博朋克 | Cyberpunk, neon lights, futuristic | 赛博朋克，霓虹灯光，未来感 | 科技、炫酷 |
| 国风水墨 | Ink wash painting, Chinese traditional | 水墨风格，国风，留白 | 传统文化、养生 |

**更多风格详见**：[references/02-style-guide.md](./references/02-style-guide.md)

#### 3.7 AI提示词生成器工作流

**批量生产时的效率神器**——让AI帮你生成提示词：

```
第一步：输入模板，生成"提示词生成器"
  → "请帮我生成一个图片提示词生成prompt，
     参考我的提示词'[你的模板提示词]'，
     要求保持人物特征不变，服装不变，仅变动作，
     并且符合我提供的文字。"

第二步：输入文案，自动获取含固定角色特征+动态动作的提示词

第三步：将提示词发送至AI绘画工具生成图片
```

#### 3.8 文案匹配图片三步法（来源：文案匹配图片提示词技巧）

**双重AI协作，实现图文精准匹配**：

```
第一步：利用Coze生成专属图片提示词生成器
  → 定义角色固定特征+风格+动作描述规则

第二步：通过豆包/AI解析文案，生成匹配的提示词
  → 解析文案中的动作、情绪、场景

第三步：生成图片，人物风格一致、动作与文案精准匹配
  → 输出到AI绘画工具生成
```

#### 3.9 批量生产提示词模板（来源：趣味漫画10W+教程）

**超级图图V4.0工作流**：

```
第一步：上传参考漫画 → AI自动解析获取提示词
第二步：使用解析出的提示词模板
第三步：一键批量生成相似风格的漫画
```

**全自动化公众号漫画生成**：

```

[上传素材库] → [图文排版] → [选取封面] → [发布草稿箱]
```

**优势**：输入主题即可一键生成带漫画插图的公众号文章并自动存入草稿箱

**输入**：提示词 + 角色卡参考图（如有）
**输出**：高质量漫画图片（每格分镜一张）

**目标**：将提示词转化为高质量漫画图片。

#### 4.3 角色一致性四大方法（来源：角色一致性保持技巧）

#### 4.2 生成流程

```
编写提示词 → 选择工具和模型 → 设置参数(比例/分辨率) → 生成图片 → 质量检查 → 不满意则迭代优化
```

#### 4.3 关键参数设置

| 用途 | 推荐比例 | 说明 |
|------|---------|------|
| 公众号文章配图 | 4:3 或 16:9 | 横版适配阅读 |
| 公众号封面 | 21:9 或 2.35:1 | 超宽屏 |
| 小红书/抖音 | 3:4 或 9:16 | 竖版 |
| 漫画分格 | 1:1 | 正方形 |

#### 4.4 图片质量检查清单

- [ ] 分辨率清晰，无模糊
- [ ] 人物特征与角色卡一致
- [ ] 场景元素正确，无多余元素
- [ ] 风格统一，与系列其他图匹配
- [ ] 无乱码文字
- [ ] 构图符合预期
- [ ] 光影效果协调
- [ ] 色彩搭配和谐

⏸ **暂停确认**：首张图片生成后，必须请用户选择最满意的版本作为参考基准。
确认话术：> "以上是生成的图片选项，请选择你最满意的一张作为后续参考基准。选定后我将继续生成其余分镜。"

**迭代规则**：如果用户不满意，最多迭代3次。3次后仍不满意，建议：
- 调整提示词中的风格关键词
- 更换AI绘图工具
- 修改角色卡设定

### Step 5: 图文整合与发布

**前置条件**：Step 4已完成，图片素材已生成
**输入**：漫画图片 + 文案/对话内容
**输出**：排版完成的漫画内容，可直接发布到公众号

**目标**：将生成的图片与文案整合，发布到公众号等平台。

#### 5.1 图文整合流程

```
撰写/优化文案 → 按分镜排列图片 → 手动添加对话框和文字 → 排版美化 → 发布
```

#### 5.2 对话框添加规范

**关键原则**：不在AI提示词中包含文字，对话框在排版阶段手动添加。

| 元素 | 添加方式 | 工具 |
|------|---------|------|

## 边界规则

### 这个Skill不能做什么

- ❌ 替代专业漫画师的原创绘画能力
- ❌ 保证100%角色一致性（AI工具本身存在随机性）
- ❌ 自动完成公众号排版和发布（需配合 wechat-article-publisher skill）
- ❌ 生成高质量文字嵌入图片（AI文字渲染仍不稳定）
- ❌ 替代用户进行选题判断和内容价值评估
- ❌ 纯手绘漫画教学（若用户明确说"手绘""不用AI""自己画"，说明此Skill专注于AI辅助漫画创作）

### 何时需要人工介入

- ⚠️ 角色首次设计——需要人工确认角色卡设定
- ⚠️ 首张图片生成——需要人工选择最满意的版本作为参考基准
- ⚠️ 涉及专业医疗/法律内容——需要专业人士审核准确性
- ⚠️ 商业变现决策——需要根据实际情况判断
- ⚠️ 跨平台发布——各平台规则不同，需人工适配

## 注意事项

1. **工具可用性**：AI工具的免费额度和功能可能随时变化，使用前确认当前状态
2. **版权合规**：AI生成图片可商用但需标注"AI创作"，不可冒充手绘原创
3. **平台规则**：不同平台对AI生成内容有不同标注要求，发布前确认
4. **内容质量**：AI是效率工具，内容质量的核心仍取决于创作者的洞察和判断
5. **迭代思维**：首稿永远不是终稿，提示词需要反复迭代优化
6. **一致性优先**：系列漫画的角色一致性比单张图片质量更重要
