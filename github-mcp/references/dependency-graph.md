# GitHub MCP - Dependency Graph

## 概述

本Skill提供GitHub API的 **Dependency Graph** 相关操作能力，包含 **3** 个工具。

## 工具列表

### 1. github_dependency_graph_diff_range

**描述**: Get a diff of the dependencies between commits

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| owner | 是 | owner |

---

### 2. github_dependency_graph_export_sbom

**描述**: Export a software bill of materials (SBOM) for a repository.

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| owner | 是 | owner |

---

### 3. github_dependency_graph_create_repository_snapshot

**描述**: Create a snapshot of dependencies for a repository

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| owner | 是 | owner |

---
