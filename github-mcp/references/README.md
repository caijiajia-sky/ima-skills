## 快速开始

```bash
# 安装 GitHub MCP
npm install github-rest-mcp

# 或从 GitHub Packages 安装
npm install @eyalm321/github-mcp
```

## 环境配置

```bash
export GITHUB_TOKEN=ghp_your_token_here
export GITHUB_MCP_CATEGORIES=repos,issues,pulls,actions
```
