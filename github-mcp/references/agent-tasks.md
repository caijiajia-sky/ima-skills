# GitHub MCP - Agent Tasks

## 概述

本Skill提供GitHub API的 **Agent Tasks** 相关操作能力，包含 **5** 个工具。

## 工具列表

### 1. github_agent_tasks_list_tasks_for_repo

**描述**: List tasks for repository

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| owner | 是 | owner |

---

### 2. github_agent_tasks_create_task

**描述**: Create a task

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| owner | 是 | owner |

---

### 3. github_agent_tasks_get_task_by_repo_and_id

**描述**: Get a task by repo

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| owner | 是 | owner |

---

### 4. github_agent_tasks_list_tasks

**描述**: List tasks

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| per_page | 否 | The number of results per page (max 100). |

---

### 5. github_agent_tasks_get_task_by_id

**描述**: Get a task by ID

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| task_id | 是 | task_id |

---
