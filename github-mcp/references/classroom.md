# GitHub MCP - Classroom

## 概述

本Skill提供GitHub API的 **Classroom** 相关操作能力，包含 **6** 个工具。

## 工具列表

### 1. github_classroom_get_an_assignment

**描述**: Get an assignment

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| assignment_id | 是 | assignment_id |

---

### 2. github_classroom_list_accepted_assignments_for_an_assignment

**描述**: List accepted assignments for an assignment

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| assignment_id | 是 | assignment_id |

---

### 3. github_classroom_get_assignment_grades

**描述**: Get assignment grades

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| assignment_id | 是 | assignment_id |

---

### 4. github_classroom_list_classrooms

**描述**: List classrooms


---

### 5. github_classroom_get_a_classroom

**描述**: Get a classroom

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| classroom_id | 是 | classroom_id |

---

### 6. github_classroom_list_assignments_for_a_classroom

**描述**: List assignments for a classroom

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| classroom_id | 是 | classroom_id |
