# GitHub MCP - Markdown

## 概述

本Skill提供GitHub API的 **Markdown** 相关操作能力，包含 **2** 个工具。

## 工具列表

### 1. github_markdown_render

**描述**: Render a Markdown document

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| body | 否 | Request body (JSON object) |

---

### 2. github_markdown_render_raw

**描述**: Render a Markdown document in raw mode

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| body | 否 | Request body (JSON object) |

---
