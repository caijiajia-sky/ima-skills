# GitHub MCP - Licenses

## 概述

本Skill提供GitHub API的 **Licenses** 相关操作能力，包含 **3** 个工具。

## 工具列表

### 1. github_licenses_get_all_commonly_used

**描述**: Get all commonly used licenses

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| featured | 否 | featured |

---

### 2. github_licenses_get

**描述**: Get a license

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| license | 是 | license |

---

### 3. github_licenses_get_for_repo

**描述**: Get the license for a repository

**参数**:

| 参数名 | 必填 | 描述 |
|--------|------|------|
| owner | 是 | owner |

---
