# 知识清单制作完整示例

## 场景

用户说："帮我做一份Python基础的知识清单"

## Phase 1：需求锁定

- **主题与范围**：Python基础，入门级核心知识
- **目标读者**：编程初学者
- **素材来源**：需要搜索

确认语："我将为你制作一份关于Python基础的知识清单，覆盖数据类型与变量、流程控制、函数与模块、面向对象基础、常用标准库5个核心模块，面向入门水平读者，每个知识点配简明解释。"

## Phase 2：信息分治

水平拆解为5个模块：数据类型与变量 → 流程控制 → 函数与模块 → 面向对象基础 → 常用标准库
垂直拆解每个模块为3-5个三级要点

## Phase 3：三点结构重组

以"字符串处理"为例的三点法表达：
- 第一点：创建与基本操作（拼接、切片、重复）
- 第二点：格式化方法（f-string、format()、%）
- 第三点：常用方法（split/join、strip、find/replace）

## Phase 4：渐进式封装输出

## 📐 一、数据类型与变量

### 1.1 基本数据类型
核心解释：Python有4种基本数据类型：int（整数）、float（浮点数）、str（字符串）、bool（布尔值）
- **int**: 任意大小的整数，如 `42`
- **float**: 带小数的数字，如 `3.14`
- **str**: 用引号括起来的文本，如 `"hello"`
- **bool**: True/False，常用于条件判断
💡 Python中变量无需声明类型，直接赋值即可
